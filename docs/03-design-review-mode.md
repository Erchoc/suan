# 复习模式 — 设计文档

> 文档版本：v1.0 · 2026-03-14
> 状态：待确认 → 实现

---

## 一、定位

**目标用户**：学生（孩子）、家长辅导

**核心场景**：针对性刷题，巩固薄弱知识点。区别于摸底考试（诊断性），复习模式是**练习性**的：
- 无时间压力
- 答后即时反馈（对/错 + 解析展示）
- hint 默认开启
- 可随时中断，进度自动保存

---

## 二、路由

```
/review                   复习入口页（来源选择）
/review/:sessionId        复习答题页
```

---

## 三、入口来源

### 3.1 导航栏直达
顶部导航新增「🔖 复习」链接 → `/review`（金刚区入口）

### 3.2 知识图谱节点
点击任意知识点 → 弹出信息面板 → 「进入复习」按钮 → `/review?kp=5-18`（预填知识点来源）

### 3.3 诊断报告页
报告页顶部摘要卡片新增「复习错题」按钮 → `/review?session=xxx`（预填报告来源）

## 五、复习答题页（/review/:sessionId）

### 布局

与摸底考试页相似，差异点：

```
┌─────────────────────────────────────────────────────┐
│  Nav                                  [结束复习]     │
├──────────────┬──────────────────────────────────────┤
│              │                                       │
│  题目导航    │  当前题目（QuestionCard）              │
│              │                                       │
│  进度：      │  [hint 提示] ← 默认展开               │
│  12 / 47    │                                       │
│             │  [提交答案]                            │
│  ✅ 已答对  │                                       │
│  ❌ 已答错  │  ── 提交后显示 ──────────────────────  │
│  ⬜ 未答    │  ✅ 回答正确！/ ❌ 正确答案是：xxx     │
│             │                                       │
│  [来源标签] │  解析：...                             │
│  错题/收藏  │  常见错误：...                         │
│             │                                       │
│             │  [下一题 →]   [重做此题]               │
└─────────────┴──────────────────────────────────────┘
```

### 核心交互差异（vs 摸底考试）

| 功能 | 摸底考试 | 复习模式 |
|------|----------|----------|
| 计时 | 可配置倒计时 | 无（记录用时但不显示） |
| 提交时机 | 全部做完统一提交 | 每道题单独提交 |
| 反馈时机 | 提交全卷后看报告 | 每题提交后即时显示 |
| hint 默认 | 折叠 | 展开 |
| solution 展示 | 报告页查看 | 答题页即时展示 |
| 错题标记 | 自动 | 可手动加入错题本 |

### 答题判断
- 答对 → 绿色勾，进度格子变绿，自动 1.5s 后可点下一题
- 答错 → 红色叉 + 展示正确答案 + 解析，手动点「下一题」

### 进度恢复
- session 存入 localStorage，关闭页面后重新打开自动恢复到上次题目

## 六、数据模型

### 新增类型（types/index.ts）

```typescript
type ReviewSourceType = 'report' | 'bookmarks' | 'kps'

interface ReviewSource {
  type: ReviewSourceType
  sessionIds?: string[]  // type='report' 时：来源的考试 session ID
  kpIds?: string[]       // type='kps' 时：选中的知识点 ID 列表
}

interface ReviewSession {
  sessionId: string
  sources: ReviewSource[]       // 支持多来源混合
  questions: Question[]
  answers: Record<string, string[]>
  choiceAnswers: Record<string, string>
  results: Record<string, 'correct' | 'wrong' | 'skipped'>
  startedAt: number
  completedAt?: number
}
```

### 新增 Store（stores/reviewStore.ts）

```typescript
interface ReviewStore {
  sessions: Record<string, ReviewSession>
  createSession(sources: ReviewSource[], questions: Question[]): string
  submitAnswer(sessionId: string, questionId: string, answer: string[]|string): void
  completeSession(sessionId: string): void
  clearOldSessions(): void  // 保留最近 10 个
}
```

## 七、知识图谱节点改动

`KnowledgeGraph` 组件中，点击知识点打开 detail 面板，新增两个按钮：

```
[进入预习 →]   [进入复习 →]
```

点击「进入复习」→ 跳转 `/review?kp={kpId}`

## 八、不在本期范围

- 复习统计报告（复习了多少道，正确率多少）
- 智能推题（根据错误率自动推荐题目）
- 错题本独立页面（当前集成在入口页）
- 多设备同步
