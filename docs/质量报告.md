## 四、安全审计

- 浏览器不读取任何 AI 密钥环境变量，只调用同源 `/api/ai/chat`。
- `API_KEY` 通过 Cloudflare Worker Secret 注入；仓库、构建输入、错误响应和截图均不含真实值。
- Worker 拒绝客户端 `system` 消息，在服务端构造系统提示词。
- 请求体最大 64 KiB，消息数、单条长度、总长度、知识点字段和年级均有边界。
- 生产流量优先按可信 `CF-Connecting-IP` 每 60 秒限制 12 次；本地环境回退到稳定客户端 UUID。
- 上游网络错误与非成功状态统一映射为安全的 502，不向浏览器透传上游错误正文。
- API 响应带 `x-trace-id`、`cache-control: no-store`、`x-content-type-options: nosniff` 和结构化日志。
